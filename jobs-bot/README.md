# OOOPS Jobs — Telegram дайджест заказов

Отдельный сервис внутри репозитория OOOPS. **Не меняет сайт студии.**
Каждый день GitHub Actions читает **только публичные** Telegram-каналы,
отбирает проекты под компетенции OOOPS и публикует до 8 вакансий/заказов
в рабочий Telegram-чат.

## Направления
- Автоматизация, интеграции, API, Telegram-боты, парсеры, CRM
- Разработка сайтов, Frontend/Backend, Python, веб-сервисы, MVP, Mini Apps
- UX/UI, аудит интерфейсов и UX-исследования
- Презентации, графика, инфографика
- Брендинг и айдентика
- Контент, SMM, монтаж и видео
- Аналитика данных и дашборды

Это фильтр по ключевым словам и контексту (эвристика); здесь **нет обещания,
что каждый заказ проверен человеком или оценён нейросетью**. Каждая ссылка
ведёт на исходное объявление. Мы не читаем закрытые чаты и не отвечаем
заказчикам автоматически.

## Первичная настройка (один раз)

1. В Telegram откройте официального **@BotFather**, создайте бота
   командой /newbot и сохраните выданный токен **не в переписке**.
2. Добавьте созданного бота в рабочую Telegram-группу OOOPS.
   Отправьте в группе команду /start или /chatid, адресованную боту.
3. В GitHub откройте репозиторий ulko31/luna →
   **Settings → Secrets and variables → Actions → New repository secret**.
   Создайте секрет **OOOPS_JOBS_BOT_TOKEN** со значением токена.
4. Чтобы безопасно узнать ID группы: откройте
   **Actions → OOOPS Jobs — ежедневные заказы → Run workflow**,
   установите **mode = discover**. После выполнения найдите в логах
   строку `group: -100...`. Скрипт не выводит токен и сообщения.
5. Создайте второй секрет **OOOPS_JOBS_CHAT_ID** со значением этого ID.
6. Снова запустите **Run workflow**, оставив **mode = send**.
   В чате должна появиться тестовая подборка (или сообщение,
   что сегодня подходящих объявлений нет).
7. Автоматический дайджест: **09:17 по Москве ежедневно**.
   GitHub Actions выполняет запланированные задания приблизительно,
   иногда с задержками. Можно изменить cron в файле workflow.

### Почему не нужно присылать токен сюда
Токен даёт контроль над ботом. Он должен быть только в GitHub Actions secrets.
Если токен случайно утечёт, его можно перевыпустить в BotFather.

## Источники и отбор
По умолчанию:
`zakaz_design, GetClient, FreeVacanciesIT, frilans, Koteyka_Freelancer,
vacancysmm, designer_jobs, uxui_jobs, jobgeeks, fordev, python_jobs`.

Для работы берутся публичные страницы `t.me/s/<channel>`.
Если Telegram блокирует просмотр источника, бот пропускает его и
фиксирует проблему в логах. Некоторые каналы могут быть недоступны
для этого метода. Даты публикаций старше 48 часов не попадают в подборку.
Ранжирование учитывает соответствие услугам OOOPS, признаки оплаты и
проектный формат. Прямые дубли по ссылке удаляются, похожие сообщения
из разных каналов могут повторяться.

Не выбираются очевидная самореклама, офисные вакансии и подозрительные
предложения со вступительными взносами. Это не полноценная проверка
работодателя: команда обязана самостоятельно проверять условия.

## Проверка локально
Node.js >=20:
```bash
cd jobs-bot
npm test
DRY_RUN=1 node digest.mjs
```

Для добавления новых источников отредактируйте массив CHANNELS
в `digest.mjs`. Учитывайте правила доступа каждого ресурса.

## Возможные улучшения
- Одобрение кандидатов перед публикацией и отслеживание статусов в YouGile.
- Сохранение истории объявлений между днями в базе данных.
- Необязательная AI-проверка релевантности через API при согласии на
  возможную стоимость вызовов.
- Telegram-команды и кнопки требуют постоянно запущенного webhook-бота;
  текущая версия — **ежедневная односторонняя рассылка**, не интерактивный бот.
