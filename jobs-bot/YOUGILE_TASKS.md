# OOOPS — задачи для переноса / сверки с YouGile
> Черновик, НЕ синхронизирован с YouGile. Проверьте существующие карточки, не создавайте дубликаты.

## Срочно / бот OOOPS Jobs

### Проверить Dprofile в ежедневном дайджесте
- **Раздел:** Автоматизация / Привлечение заказов
- **Приоритет:** высокий
- **Статус:** код диагностики внедрён; фактический запуск с Dprofile не подтверждён
- **Сделать:** GitHub Actions → OOOPS Jobs → Run workflow → `preview`;
  открыть логи `[source] dprofilefreelance`, проверить статус `ok / empty / unavailable`,
  сравнить с доступностью публичного каталога Dprofile.
- **Готово, когда:** логи показывают понятный статус источника,
  а при доступных актуальных заказах они появляются в подборке;
  ошибки Dprofile не мешают остальным источникам.
- **Ссылка:** https://github.com/ulko31/luna/actions/workflows/ooops-jobs.yml

### Проверить ежедневную доставку в тему Telegram
- **Раздел:** Автоматизация / Привлечение заказов
- **Приоритет:** высокий
- **Сделать:** запустить `send`, убедиться, что сводка приходит в нужную тему,
  проверены 12 каналов, нет ошибок у тестов и отправки.
- **Готово, когда:** успешный запуск и сообщение в Telegram.
- **Данные доступа:** токен, ID группы и ID темы только в GitHub Actions secrets;
  не сохранять их в тексте задачи.

### Улучшить релевантность подборок
- **Раздел:** Автоматизация / Привлечение заказов
- **Приоритет:** средний
- **Сделать:** отследить за неделю ложные совпадения и пропущенные заказы;
  расширить ключевые слова по Python, веб-разработке, API, CRM,
  Telegram Mini Apps, интеграциям, UX, презентациям, контенту.
- **Готово, когда:** есть 10–15 проверенных объявлений с оценкой качества подбора.

### Проверить возможность более полного мониторинга Dprofile
- **Раздел:** Автоматизация / Привлечение заказов
- **Приоритет:** средний
- **Сделать:** изучить публичные / разрешённые источники объявлений;
  не обходить авторизацию/ограничения сайта.
- **Готово, когда:** выбран устойчивый источник либо зафиксировано,
  что официальный Telegram-канал остаётся единственным надёжным способом.

## Продвижение и портфолио

### Опубликовать на Dprofile кейс SOFE
- **Приоритет:** высокий
- **Сделать:** использовать реальную обложку / реальные скриншоты,
  корректно описать вклад студии, UX, дизайн и MVP.
- **Готово, когда:** опубликован оформленный кейс с ссылкой на сайт/проект.

### Опубликовать на Dprofile кейс Time Lab
- **Приоритет:** высокий
- **Сделать:** реальные интерфейсы и демоданные без раскрытия данных учеников;
  раскрыть задачу автоматизации и сценарии работы.
- **Готово, когда:** оформленный кейс опубликован.

### Подготовить портфолио презентаций и графики
- **Приоритет:** средний
- **Сделать:** выбрать оригинальные работы и презентабельную обложку,
  указать роль и исходные материалы; не использовать вымышленные результаты.
- **Готово, когда:** портфолио пригодно для персональных откликов.

### Отработать четыре найденных заказа Dprofile
- **Приоритет:** высокий
- **Сделать:** проверить актуальность и бюджеты; сначала UX-аудит AI-сервиса,
  лендинг AI-тревел-ассистента; BIOME только после проверки бюджета;
  крупный 3D-конфигуратор только после оценки партнёров/команды.
- **Готово, когда:** по каждому — отклик / отказ с причиной и ответственным.

### Учёт откликов
- **Приоритет:** высокий
- **Сделать:** карточки с полями источник, дата, контакт,
  специализация, бюджет, ссылка, релевантный кейс, статус, следующий шаг.
- **Готово, когда:** каждый отправленный отклик можно найти и отследить.

## Регулярный обзор
- Каждую неделю: количество подходящих заказов, откликов, ответов,
  переговоров, предложений, договорённостей и фактической выручки.
- Не считать количество подписчиков или отправленных сообщений
  главным показателем успеха.
